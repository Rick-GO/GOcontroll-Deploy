Verify your download

Compute the SHA-256 checksum of the file you downloaded and compare it with the one shown next to the file. If they differ, the file is incomplete or damaged: download it again and do not install it.

Linux
sha256sum rootfs.ext4.zst
macOS
shasum -a 256 rootfs.ext4.zst
Windows (PowerShell)
Get-FileHash -Algorithm SHA256 .\rootfs.ext4.zst

Use the name of your file. Windows shows the checksum in capitals; upper and lower case are the same checksum.
